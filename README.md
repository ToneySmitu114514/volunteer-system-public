# 福州三中志愿登记系统

开发组任务登记与志愿时长分配系统，以网站形式呈现数据、管理数据。

## 功能
- 任务登记：新增 / 查看 / 编辑 / 删除任务（标题、内容、日期时间、地点、参与成员、志愿时长）
- 志愿时长分配：支持「平均分配（时长÷人数）」与「全员计满」两种规则，自动汇总每位成员时长，可查单人明细与总计
- 成员管理：成员增删改，含学籍辅号、备注
- 数据可视化：仪表盘 + 各成员志愿时长柱状图 + 每月时长趋势折线图（纯手写 SVG，不依赖任何 CDN，离线可用）
- 简单登录：口令访问，未登录无法调用数据接口；支持在页面修改口令
- 数据持久化：SQLite 存储，关闭服务不丢失

## 技术栈
- 前端：HTML + CSS + 原生 JavaScript，零依赖
- 后端：Python 3 标准库（http.server + sqlite3），无需 pip install 任何第三方包

## 本地运行
```
python server.py
```
启动后浏览器打开 http://127.0.0.1:8088 ，默认口令 985211（登录后可在右上角「修改口令」更换）。

## 目录结构
```
volunteer-system-py/
├── server.py        # 后端：HTTP 服务 + SQLite + REST API
├── deploy.sh        # 一键部署脚本（Debian/Ubuntu）
├── static/
│   ├── index.html   # 页面结构
│   ├── style.css    # 样式
│   ├── app.js       # 前端逻辑与 SVG 图表
│   └── avatar.*     # 站点头像
└── app.db           # SQLite 数据库（运行时生成，已被 .gitignore 忽略）
```

## 部署到服务器
见 deploy.sh（自动安装 Nginx、配置反向代理、注册开机自启）。默认口令 985211，公网部署后请第一时间在页面修改。
